# readOut OG variants

Six 1200 × 630 Open Graph compositions derived from the cyan and orange curves in the readOut app icon.

The final images use deterministic HTML, CSS and inline SVG only. No generated imagery or fake interface elements.

Selected direction: **Classic**. The canonical export is `output/og-final.png`.

## Preview

```sh
python3 -m http.server 4173 --bind 0.0.0.0 --directory og-variants
```

## Re-render

Open `render.html?variant=N` in a 1200 × 630 browser viewport and capture the page. Final exports live in `output/`.
